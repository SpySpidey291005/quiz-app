# Code With AI Quiz

A clean, responsive, and interactive web-based quiz application that tests foundational knowledge on AI, coding best practices, and web development fundamentals.

## 🚀 Live Demo
- **Live Application:** [quiz-app-three-rho-14.vercel.app](https://quiz-app-three-rho-14.vercel.app)

---

## ✨ Features
- **Dynamic Question Loading:** Renders questions and interactive options dynamically using vanilla JavaScript.
- **Instant Answer Validation:** Ensures single-attempt selection per question with dynamic score updates.
- **Score Calculation:** Displays total score upon completion.
- **Modern UI Design:** Styled with custom CSS properties, smooth hover effects, dark radial gradient backgrounds, and fully responsive layouts.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, CSS variables, Flexbox layout, and interactive state transitions.
- **JavaScript (ES6):** DOM manipulation, state management, and event handling.
- **Vercel:** Application hosting and deployment.
